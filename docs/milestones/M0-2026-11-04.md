# M0 — Research and private recovery lab opened

Date: **4 November 2026**. Scope version: `m0-2026-11-04`.

DogWars Mobile has entered research and private recovery work for an iPhone-first adaptation of WARDOGS, with independent multiplayer as a separate engineering workstream. This is an initial lab milestone. It is not a playable game milestone.

## Checklist accounting

The lab/toolchain sector has **6 of 8** listed tasks completed (**75%**). Data recovery has **1 of 6** listed tasks completed (**16.7%**, the package inventory only). Native code, maps, gameplay, vehicles, independent multiplayer and iPhone delivery each have **0** completed listed tasks. These are named task counts in the M0 checklist, not proportions of original game code or a predicted share of the remaining work. The complete game scope is not yet known; global game completion is not measurable.

The public community catalog and the two optional raw bulk payloads have evidence receipts, but do not complete the task to export data tables from the owned build. Current-build mappings, meaningful local decoding, editor asset reconstruction and all game runtime milestones remain pending.

## Open work

- Resolve version-compatible archive inputs and current-build mappings; the package inventory is complete and the isolated source copy has size/selected-hash verification.
- Record actual extraction coverage, failures and dependencies.
- Reconstruct supported assets and original custom classes; determine the native function work still required.
- Configure the matching Unreal C++ toolchain and integrate the recovered content.
- Prepare the Mac/Xcode signing environment when available, then compile and run a real iPhone build.
- Define and implement the independent game services and validate a controlled multi-client session.

There is currently no playable game download, no DogWars Mobile IPA, no physical iPhone runtime evidence and no validated independent server runtime.
